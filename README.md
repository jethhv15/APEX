# APEX

> Android Performance EXperience

APEX is a KernelSU module designed specifically for the Poco F6 (peridot)
running Clover ROM and Ulquiorra Kernel.

## Vision

APEX is not a tweak collection.

APEX is an evidence-driven runtime that minimizes system-side latency by
working with Android Framework instead of fighting it.

## Design Principles

- Evidence First
- Minimal Intervention
- Framework Native
- Clover First
- Zero Placebo

## Development Workflow

Every feature follows the same lifecycle:

Audit
→ Decision
→ Apply
→ Verify
→ Restore
